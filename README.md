# Exercice 3 : Programme interactif avec le SDK JavaScript

Ce projet réimplémente le script interactif en utilisant le SDK OpenAI configuré avec le baseURL de RodiumAi sous Node.js.

## Fonctionnalités
- Etape 1 (Chat) : Envoi d'une question à openai/gpt-4o-mini via le SDK.
- Etape 2 (Image) : Génération d'un carré rouge avec google/gemini-3.1-flash-lite-image.
- Etape 3 (Video) : Génération d'une animation de 4 secondes avec google/veo-3.1-lite.

## Installation

npm install

## Lancement

node main.js
